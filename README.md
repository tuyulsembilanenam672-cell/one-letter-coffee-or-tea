One letter, nothing else: **A stands for coffee**.

Coffee is the bolder, more alive stance — the drink of deadlines, late builds and first light — and it lands as the more vivid and more honest answer than the calm, safe tea pick.

The program writes exactly the single character `A` (one byte, no trailing newline) to `/output/entry.txt`.
